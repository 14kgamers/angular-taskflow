# TaskFlow

Aplicação Angular moderna para gerenciamento de tarefas.

## Preview

Projeto desenvolvido para demonstrar:
- Arquitetura Angular
- Standalone Components
- Lazy Loading
- Services
- Organização escalável
- Componentização


## Tecnologias

- Angular
- TypeScript
- SCSS


## Estrutura

```text
src/app
├── core
├── features
├── shared
└── layout
```

## Funcionalidades

- Listagem de tarefas
- Dashboard moderno
- Cards responsivos
- Organização enterprise
